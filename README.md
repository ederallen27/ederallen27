Plataforma funcional voltada para barbearias, desenvolvida para organizar a operação diária e melhorar a experiência do cliente.

## 👥 TheraPrime CRM & Archive Sync

Sistema interno de gestão de leads e clientes integrado ao ecossistema TheraPrime.

O fluxo acompanha etapas como:

`Lead → Briefing → Proposta → Contrato → Pagamento → Desenvolvimento → Revisão → Entrega`

Também foi desenvolvido um sistema de sincronização e arquivamento para registrar eventos importantes do CRM com validação, logs, hashes SHA-256, prevenção de duplicados e quarentena de pacotes inválidos.

> Parte do código e das configurações permanece privada por segurança e proteção de dados.
